# 人的介入ログ

ユーザーが指摘・修正・誘導する必要があった事象を蓄積。Claude Code が単体で完結できる範囲を広げるための記録。

## 方針

- **追記タイミング**: セッション末 or PR 作成時、新しい順に上から積む
- **粒度**: 1 件 = 1 行を原則。詳細は PR / コミット / 該当ファイルから辿れるので書かない
- **書式**: `- [カテゴリ] 状況の要点 → 防止策`
- **カテゴリ**:
  - `指示違反` … CLAUDE.md / スキル / メモリ で定義済みのルールを守らなかった
  - `バグ` … 実装ミスで動かない・副作用
  - `仕様理解` … API / フレームワーク / データモデルの前提を誤って実装
  - `環境` … OS / 依存設定の前提ミス
  - `コミュニケーション` … 質問の曖昧さ・確認過多/不足・主張と検証の乖離
  - `プロセス` … コミット粒度・PR 段取り・検証段取り・自発性
- **対象外**: 1 ターンで解決した軽微な指示変更（言い回し調整など）
- **分析サイクル**: 10〜20 件 or 月次で傾向集計 → 頻出は CLAUDE.md / スキル / メモリ に昇格。昇格済みは行末に `→ <反映先>` を追記
- **過去ログの剪定**: ルール化された行は半年〜1年後に archive へ退避
